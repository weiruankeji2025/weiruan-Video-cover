# 威软视频封面提取器

> 🎬 AI 智能提取 · 一键生成精美封面

一个全自动化的视频封面提取应用，用户上传视频后自动提取符合视频主题的 5 张封面供用户选择。

![版本](https://img.shields.io/badge/version-1.0.0-blue)
![许可证](https://img.shields.io/badge/license-MIT-green)

## ✨ 产品特色

- 🎯 **打开即用**：无需注册登录，打开网页即可使用
- 🚀 **全自动提取**：上传视频后自动智能提取 5 张高质量封面
- 🎨 **极简设计**：科技感十足的渐变色 UI，流畅的动画效果
- 📱 **响应式布局**：完美适配桌面端和移动端
- 💾 **纯前端实现**：所有操作在浏览器完成，无需后端服务器
- 🔐 **本地存储**：使用 localStorage 安全存储用户数据

## 🎯 核心功能

### 1. 每日签到系统
- ✅ 每天签到一次
- ✅ 记录签到时间
- ✅ 显示连续签到天数
- ✅ 签到数据持久化

### 2. 视频封面提取
- ✅ 支持多种视频格式（MP4、AVI、MOV 等）

  - ✨ 清晰（1280x720）
  - 💫 一般（854x480）
- ✅ 拖拽上传支持
- ✅ 实时进度显示

### 3. 个人数据面板
- 📊 上传/下载次数统计
- 📈 使用趋势图（Canvas 绘制）
- 📝 历史记录查看
- ⏱️ 使用时长统计

## 🚀 快速开始

### 前置要求

- Node.js 14+ (仅用于运行本地服务器)
- 现代浏览器（Chrome、Firefox、Safari、Edge）

### 安装步骤

1. **克隆或下载项目**
```bash
cd weiruan-video-cover
```

2. **安装依赖**
```bash
npm install
```

3. **启动应用**
```bash
npm start
```

应用将自动在浏览器中打开 `http://localhost:8080`

### 替代启动方式

如果不想安装 Node.js，可以使用任何静态文件服务器，例如：

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080

# PHP
php -S localhost:8080
```

## 📖 使用指南

### 1. 打开应用

直接访问 `http://localhost:8080/app.html` 或运行 `npm start`，应用会自动以游客模式打开，无需注册登录。

### 2. 提取视频封面

1. **每日签到**（可选）
   - 点击"今日签到"按钮
   - 查看连续签到天数

2. **选择输出质量**
   - 高品质（1920x1080）
   - 清晰（1280x720）
   - 一般（854x480）

3. **上传视频**
   - 点击上传区域选择文件
   - 或拖拽视频文件到上传区域
   - 等待自动提取封面

4. **选择并下载封面**
   - 浏览提取的 5 张封面
   - 点击选择喜欢的封面
   - 点击"下载选中封面"按钮

### 3. 查看个人面板

1. 点击导航栏的"个人面板"
2. 查看统计数据：
   - 上传次数
   - 下载次数
   - 连续签到天数
   - 总使用时长
3. 查看使用趋势图
4. 浏览上传/下载历史

## 💾 数据存储

所有数据使用浏览器 localStorage 存储，包括：

- **用户数据** (`weiruan_users`)
  - 用户ID、用户名、邮箱/手机、密码
  - 注册时间、最后登录时间

- **签到数据** (`weiruan_checkin`)
  - 连续签到天数、总签到天数
  - 最后签到日期、签到历史

- **上传历史** (`weiruan_upload`)
  - 文件名、文件大小
  - 输出质量、封面数量
  - 上传时间

- **下载历史** (`weiruan_download`)
  - 封面名称、输出质量
  - 下载时间

- **统计数据** (`weiruan_stats`)
  - 上传/下载次数
  - 使用时长
  - 每日统计（用于趋势图）

## ⚠️ 注意事项

1. **文件大小限制**：支持上传不超过 2GB 的视频文件
2. **浏览器兼容**：请使用现代浏览器以获得最佳体验
3. **数据安全**：数据存储在本地浏览器，清除浏览器数据会导致数据丢失
4. **视频格式**：支持浏览器可播放的所有视频格式
5. **性能优化**：大视频文件提取封面可能需要较长时间

## 🐛 故障排除

### 问题：验证码不显示
**解决方案**：刷新页面或点击验证码刷新按钮

### 问题：视频上传后没有反应
**解决方案**：
1. 检查视频格式是否支持
2. 检查视频文件是否损坏
3. 尝试较小的视频文件

### 问题：封面提取失败
**解决方案**：
1. 确保浏览器支持 Canvas API
2. 检查浏览器控制台错误信息
3. 尝试其他视频文件

### 问题：数据丢失
**解决方案**：
- 避免清除浏览器缓存和 Cookie
- 不要使用无痕模式
- 定期导出重要数据（未来版本将支持）
